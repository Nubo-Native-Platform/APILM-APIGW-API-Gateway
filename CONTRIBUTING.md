# Contributing to api-gateway

This repository — **`api-gateway`** — is part of the **API Lifecycle Management (APILM)** area of the **Nubo Native Platform (NNP)**. Contributions are welcome under the **Apache 2.0 License**.

## Before you start
Contribute against an open **Issue**, the published **Roadmap**, or a proposed **enhancement**. Email **contribution@nubons.com** with your approach and category first; we respond within 5 working days.

## Steps
1. Fork & clone the repository.
2. Create a focused topic branch (e.g., `feature/new-gateway-filter` or `fix/cache-eviction`).
3. Ensure all tests pass (`mvn clean verify`).
4. Open a Pull Request with a clear description and testing notes.

## Security
**Never commit secrets, tokens, `.env` files, or credentials.** See [SECURITY.md](SECURITY.md). All participation is governed by our [Code of Conduct](CODE_OF_CONDUCT.md).
